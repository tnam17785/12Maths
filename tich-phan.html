Tích phân

Nguyên hàm, tích phân xác định và ứng dụng tính diện tích, thể tích.

1. Nguyên hàm

Hàm F(x) được gọi là nguyên hàm của f(x) trên (a;b) nếu F'(x) = f(x) với mọi x ∈ (a;b).

∫ f(x) dx = F(x) + C

Một số nguyên hàm cơ bản

  • ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C (n ≠ −1)
  • ∫ 1/x dx = ln|x| + C
  • ∫ eˣ dx = eˣ + C
  • ∫ sin x dx = −cos x + C
  • ∫ cos x dx = sin x + C

2. Tích phân xác định

∫ab f(x) dx = F(b) − F(a)

Trong đó F là một nguyên hàm của f.

Tính chất: ∫ab = −∫ba và ∫aa = 0.

3. Phương pháp tính tích phân

  • Đổi biến số: Đặt t = u(x), dx = dt / u'(x).
  • Tích phân từng phần: ∫ u dv = uv − ∫ v du.

4. Ứng dụng

  • Tính diện tích hình phẳng giới hạn bởi các đường cong.
  • Tính thể tích khối tròn xoay.
  • Tính quãng đường, công... trong vật lý.
